## Look at it locally

The pages come from a local production build; every `/api` request goes to the pilot, which uses the shared database. So it shows real repositories, and anything saved through it is saved for real.

1. `eil-dashboard/.env.production.local` holds the pilot's public build settings (git-ignored; already written on this PC).
2. In `eil-dashboard`: `npx next build` (about 3 minutes), then `npx next start -p 3001`.
3. In a second terminal: `node scripts/local-preview.mjs`.
4. Open http://localhost:3000 and sign in as usual.

Library thumbnails work locally for papers stored in the pilot's bucket. Papers stored in the production bucket show the PDF tile until the release, because that bucket only lets production read it from a browser.

## Checks

- `tsc --noEmit` clean. eslint: 0 errors on all changed source files (5 warnings that were there before).
- Web tests: 1,442 of 1,442 pass (run in four batches to fit this PC's memory). Python tests: 180 of 180. Tests that pinned an old class name or line of copy now name the new one, each with a comment.
- Local production build, then every page screenshotted in light, dark and phone (65 shots) and compared with the same 65 taken before the batch; no page errors. That pass caught and fixed: the Library's "Filter and sort" folding at full width (a breakpoint Tailwind did not generate), the Library list's column headers out of line with its rows, the home hero's facts leaving one item alone on a line, "Colour" left in the map's note, and "Profile v2 - date" in the paper viewer.

Known, not changed:

- The Library's Year column shows the year the analysis found, not a reader's correction (it was so before this batch: "A comparison of the semantic networks…" shows 2003 though it was corrected to 2013). The Dashboard and Chat use the correction.
- On a phone, the chat screenshot's text is small (about 7px at 390px wide; it was about 3px). A tighter crop would cut its sentences.
- Library thumbnails show locally only for papers in the pilot's bucket (see above).
